## 3. 検査手段はあるが、環境上ローカルで検証できないもの

| 項目 | 内容 | 理由 |
|---|---|---|
| AVIF 配信 | 本番（Cloudflare Workers）では実行時に AVIF へ変換される想定 | ローカルに Cloudflare の `IMAGES` バインディングが無く、`/_vinext/image` が変換せず元形式のまま返す。**AVIF ファイルは生成済み（257KB）だが、本番での配信は未検証** |
| `vinext start` の `/assets/*` 404 | ローカルで静的アセットのサブディレクトリが 404 になる | Windows 環境でのみ確認。他 OS で再現するかは未検証。本番（Workers Static Assets）では影響しないと**推定**しているが、実デプロイでの確認はしていない |
| Cloudflare Workers への実デプロイ | — | デプロイ先アカウント・ドメインが未確定のため未実施 |
| rolldown の `plugintimings` 警告 | ビルド 1 回だけ案内行が出た | その後 10 回以上のビルドで再現せず、全文を取得できていない |

## 5. 検査手段を新たに作った項目（参考）

|---|---|---|
| No.116 コントラスト | `a11y-audit.mjs` のピクセル実測 | CSS の背景色をたどる方法では、写真の上の文字が「白／白 = 比率 1」と誤検出された。文字を透明にしてスクリーンショットを撮り、描画された背景ピクセルの平均色から算出する方式に変更 |

## 6. 未確認ではないが、限界を明示しておくもの

| 項目 | 限界 |
|---|---|
| 所要時間の計測 | **会話メッセージ単位のタイムスタンプが残っていない。** フェーズ 0・1 の開始時刻はファイル mtime とコミット時刻から挟み込んだ推定値。フェーズ 2 以降は開始時に `date` を取得しているため実測 |
| ヒアリング 58 件の解析所要時間 | 計測手段なし（ツール実行を伴わないため痕跡が残らない） |
| CLS の計測 | Chromium の `PerformanceObserver` で `layout-shift` を観測。**高速なローカル配信での値**であり、実回線での値とは異なる可能性がある |
| コントラストの背景色 | 半透明が重なる箇所は祖先をたどって合成しているが、`backdrop-filter: blur()` を使うヘッダーは背後のスクロール位置で変わる。**ヘッダーは最上部での値**で判定している |
