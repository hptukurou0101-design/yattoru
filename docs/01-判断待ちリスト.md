## B. アクセシビリティの例外

### B-1. `scroll` ガイドのコントラスト（チェック項目 No.116）

実測 **2.50:1**（基準 4.5:1）。ヒーロー画像の明るい部分の上にある白文字です。

- 対象: ヒーロー右下の縦書き「scroll」＋縦線
- 属性: `aria-hidden="true"`（**支援技術には露出しない純粋な装飾**）
- 対応済み: `text-shadow: 0 2px 10px rgba(0,0,0,.55)` を追加
- 実測方法: 文字を透明にしてスクリーンショットを撮り、描画された背景ピクセルの平均色から算出

これ以上比率を上げるには、ヒーロー画像のグラデーションを濃くする必要があります。

- [ ] 装飾として許容する
- [ ] グラデーションを濃くして基準を満たす（ヒーローの見え方が暗くなります）
- [ ] `scroll` ガイド自体を削除する
