# 作業ログ

各フェーズの所要時間を後から集計できるようにするための記録。
時刻はすべて JST（ローカル時刻）。根拠はファイル mtime / git のコミット時刻 / コマンド出力のタイムスタンプ。

## 前提

- 会話メッセージ単位のタイムスタンプは残っていないため、**開始時刻は最初の成果物の時刻からの推定**を含む。
- 推定値には「(推定)」と明記する。
